# 流程：研发费用日常管理规范

> 用法：把制度落到日常可执行的操作细则。与 03-forms/forms.md 表单、02-processes/rd-process.md 节点一一对应。

## 一、表单流转规则（顺序）
1. 研发项目立项书 → 2. 研发预算表 → 3. 工时记录表（按月） → 4. 材料领用单 →
5. 委外研发合同备案 → 6. 阶段/结题验收报告 → 7. 资本化申请审批单 → 8. 研发费用辅助账

## 二、审批权限矩阵（示例，按企业实际填）
| 事项 | 金额/层级 | 审批人 |
|---|---|---|
| 项目立项 | 全部 | {{评审委员会→总经理}} |
| 预算内支出 | ≤{{X}}万 | {{部门负责人}} |
| 预算内支出 | >{{X}}万 | {{分管副总}} |
| 预算调整 | 全部 | {{原审批层级}} |
| 资本化判定 | 全部 | {{技术负责人+财务负责人}}双签 |
| 大额/重大 | ≥{{Y}}万 | {{董事会}} |

## 三、归档周期与保管
- 工时/领料：按月归集，次月{{N}}日前完成复核。
- 辅助账：按月登记，按季结账。
- 项目档案：结题后{{30}}日内归档，保管不少于{{10}}年。
- 证据链：随项目进度录入系统 `/evidence`，结题后导出 PDF 存档。

## 四、数据质量检查清单（每月）
- [ ] 各项目费用均有 `evidence_id`（无则列待补）
- [ ] 人员人工按工时占比分摊，研发人员身份准确
- [ ] 直接投入按项目领用，无串项
- [ ] 折旧/摊销与研发工时或使用频率匹配
- [ ] 委外研发合同与成果归属齐全
- [ ] 资本化判定依据完备（6 条件）
- [ ] 加计扣除/高企/IPO 三类口径分别可列

## 五、责任追究与整改闭环
- 归集错误、证据缺失：责任人{{时限}}内补正，记录于 risk 表。
- 超预算未审批：暂停相关支出，提交说明与整改。
- 重大违规：按公司制度问责，必要时回溯调整申报数据。

## 六、与系统对接
- 表单数据录入系统对应表（projects/expenses/worktime/...）。
- 证据链统一走 `/evidence` 模块，保证可查可导出。
- 月度检查结论写入 risk/policies 供审计追溯。
